# 音乐播放器

NexBox 内置的音乐播放器,让你在游戏间隙也能轻松播放本地音乐,无需切换到其他播放器。

## 功能特性

- **本地音乐库**:自动扫描并导入本机的音频文件,按播放列表管理。
- **播放控制**:播放 / 暂停 / 上一首 / 下一首,支持随机与循环模式。
- **轻量运行**:界面简洁,播放流畅,不占用过多资源。
- **随开随用**:与工具箱深度集成,随时唤起播放。

## 使用方式

1. 进入「音乐」页面;
2. 从本机选择或导入音乐文件;
3. 建立或切换播放列表;
4. 点击播放即可。

## 说明

- 支持常见音频格式,播放列表与播放进度在本机持久化保存。
- 播放时不会干扰悬浮窗等其余功能。

## 系统媒体控制(音量浮层 / 锁屏)

播放时,新境盒会出现在 Windows 的音量浮层与锁屏界面上,显示封面、歌名、歌手与进度条;
浮层上的播放/暂停、上一曲、下一曲、拖动进度都会直接控制内置播放器。

实现方式是浏览器标准的 Media Session(见 `src/lib/media-session.ts`),不是自建的系统会话,因此:

- **只有真正在播放时才会出现**,暂停/停止后条目立即消失;
- **不占用媒体键**:未播放时按下键盘上的播放/暂停、上一曲、下一曲,由 Windows 路由给当前
  正在播放的那个软件(网易云、Spotify 等),新境盒不会抢;
- 进度条由浏览器依据 `<audio>` 元素自行推导,不需要额外推送。

若不需要这套集成,可在「设置 → 高级」关闭「系统媒体控制」开关:关闭后新境盒不再出现在
音量浮层/锁屏,媒体键完全交还系统。
