# 2026-06-27 工作日志

## 灵动岛通知图标修复

**问题：** 灵动岛通知图标映射错误——所有未识别的应用通知都显示为QQ图标。

**根因：** `src/pages/WidgetIslandPage.tsx` 中 `getAppIcon` 函数的 fallback 返回了 `"/icons/qq.png"`，导致 Chrome、Edge、Steam 等任何不匹配已知映射的应用都显示QQ图标。

**修复内容：**
1. 将 fallback 从 `"/icons/qq.png"` 改为 `"/logo/NexBoxW.png"`（NexBox 白色 logo，中性默认图标）
2. 新增常见应用图标映射：
   - Chrome/Google → `browser.svg`
   - Edge → `browser.svg`
   - Steam/Epic → `game.svg`
   - Discord/Telegram → `chat.svg`
   - OneNote/Notion/Evernote/笔记 → `note.svg`
   - Bilibili/哔哩哔哩 → `bilibili.svg`
3. 新增5个 SVG 图标文件到 `public/icons/` 目录

**参考：** NetSpeed-Dynamic-main 项目的 Vue 版本（`WidgetIsland.vue`）中 fallback 使用的是 `defaultLogo`（项目 logo），而非任何具体应用图标。

**需求：** 为灵动岛添加全局热键 Shift+F11（可自定义），支持在任意应用内快速切换灵动岛显示/隐藏。

**涉及文件：**

| 层 | 文件 | 改动 |

| Rust 后端 | `src-tauri/src/hotkey.rs` | 新增 ISLAND_SHORTCUT/ID 状态 + init/update/get/set + 2 个 Tauri 命令 + cleanup |
| Rust 后端 | `src-tauri/src/island.rs` | 新增 `toggle_island()` 函数（检测 widget 窗口可见性后 emit show/hide 事件） |
| Rust 后端 | `src-tauri/src/lib.rs` | handler 匹配分支 + setup 默认注册 "Shift+F11" + 命令注册 |
| 前端 Context | `src/contexts/app-startup-context.tsx` | 新增 `DEFAULT_ISLAND_HOTKEY` / `islandHotkey` 状态 / `loadIslandHotkey` / `saveIslandHotkey` |
| 前端设置页 | `src/pages/DynamicIslandPage.tsx` | 灵动岛设置卡片内新增 "快捷切换" HotkeyRecorder |
| 前端热键页 | `src/pages/SettingsPage.tsx` | HotkeySettings 新增 "灵动岛" 热键配置项 |
| 国际化 | `src/locales/zh.json` / `en.json` | 新增 island/islandToggle/islandToggleDesc 翻译 |

**设计模式：** 完全复用 overlay/crosshair/filter 的热键架构 —— Rust 侧 Mutex+AtomicU32 管理状态，前端通过 invoke + LazyStore 双向持久化。热键触发流程：系统快捷键 → plugin handler → shortcut.id() 匹配 → toggle_island() → emit control-island-visibility → WidgetIslandPage 动画过渡显示/隐藏。
